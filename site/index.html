Read the installation guide ↗
CONTAINERS / LINUX AMD64 
docker pull ghcr.io/salnajjar/rustysoul:beta
docker run -d --name rustysoul --restart unless-stopped \
  --read-only --cap-drop ALL --security-opt no-new-privileges --pids-limit 256 \
  --tmpfs /tmp:rw,noexec,nosuid,size=16m \
  -p 127.0.0.1:8484:8484 -p 2234:2234 \
  -e RUSTYSOUL_BIND=all -e RUSTYSOUL_ALLOW_REMOTE=true \
  -e RUSTYSOUL_PUBLISHED_TRANSFER_PORT=2234 \
  -e RUSTYSOUL_DEFAULT_USERNAME=admin \
  -e RUSTYSOUL_DEFAULT_PASSWORD=change-me-now \
  -v rustysoul-data:/var/lib/rustysoul \
  -v rustysoul-downloads:/downloads \
  -v rustysoul-library:/library:ro \
  ghcr.io/salnajjar/rustysoul:beta

Requires Docker Engine on Linux. Set environment variables and mount persistent storage; no repository checkout, Compose or configuration files are needed. The application comes from the public :beta image; no registry login needed. Configure your mounts ↗

Requires Podman on Linux. Uses environment variables and named volumes, with no configuration files to download. Quadlet remains an optional alternative for a systemd-managed service. Read the Podman guide ↗

Before you settle in

A few good questions.

Does my browser need to stay open?+

No. RustySoul runs as a daemon on your Linux server. Transfers and indexing carry on after you close the tab; open the interface again whenever you need it.

Can I access it from another computer?+

Yes. HTTP defaults to loopback on port 8484. Use an SSH tunnel or an HTTPS reverse proxy for remote access. The transfer port defaults to TCP 2234, with UPnP and diagnostics in Settings. See the connection guide.

Is RustySoul ready for everyday use?+

This is the first public beta. Automated tests cover the application, interface and container setup, alongside independent-client interoperability tests. Back up your data before upgrades and expect more field testing and refinement. See the remaining work.

Is this an official Soulseek client?+

RustySoul is an independent, open-source client. You’ll need a separate Soulseek account. Please share content only where you have the right to do so.
